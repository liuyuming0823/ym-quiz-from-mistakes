# 错因分类表（含判定依据）

把学生错误归入以下六类之一或组合。每条诊断必须引用学生作答的具体步骤作为依据，不能只贴类型标签。

## 六类错因

| 类型 | 判定依据（看学生作答的哪一步） | 典型表现 |
|---|---|---|
| 概念没理解 | 用了根本不存在 / 不适用的规则，或误解定义 | 「负数没有平方根所以不写」「把周长当面积」 |
| 概念混淆 | 两个相近概念互相串用 | 把倍数当因数、把折射当反射、把增函数当减函数 |
| 计算或符号失误 | 思路对，但在运算 / 符号 / 抄写环节出错 | 移项没变号、正负号错、把 3×4 算成 7 |
| 审题遗漏条件 | 解法方向对，但漏看题干某条件或限制 | 忽略「x>0」、没用「匀速」条件、答非所问 |
| 方法会但步骤跳错 | 知道用什么方法，中间某步逻辑断档 | 因式分解跳过检验、几何证明跳关键辅助线 |
| 表达不规范 | 结果对但书写 / 格式不达标 | 单位漏写、没写「解」、符号乱、步骤缺依据 |

## 判定顺序

1. 先看结果对不对。
2. 结果错 → 看是「方向错」还是「执行错」。
   - 方向错（用了不该用的规则 / 概念串用）→ 归「概念没理解」或「概念混淆」。
   - 执行错（思路对但算错 / 漏条件 / 跳步）→ 归「计算或符号失误」「审题遗漏条件」「方法会但步骤跳错」。
3. 结果对但过程有问题 → 归「表达不规范」或「方法会但步骤跳错」。
4. 组合错因时，主次分明：先写主因，再补次要。

# 分层提示三级

学生可逐级要，默认先给第 1 级，回应后再给下一级，不跳级。

- **第 1 级（点方向不点破）**：只说卡在哪儿的方向，不给任何解法。
  - 例：「注意一下题目里给的两个条件，它们要怎么配合用？」
- **第 2 级（给关键一步）**：点出那一步该做什么，但后续仍由学生完成。
  - 例：「先把第二个方程里的 y 用 x 表示，代入第一个。」
- **第 3 级（完整思路）**：给可执行的完整解题路径，仍是「教思路」不是「给最终答案」。
  - 例：「用代入消元法：由②得 y=… 代入①解出 x=…，再回代求 y……」

不得越过第 1 级直接给第 3 级；学生没要更多提示时，只停在已给级别。

# 变式题三种类型

出 3 道，分别覆盖，且必须自己先解一遍确认答案正确：

1. **同结构换数字** — 仅替换数值，考点与难度不变。检验学生是否真懂方法。
   - 例：原题 2x+3=11，变式 3x−5=16。
2. **换一个干扰条件** — 保留结构，改一个条件或加一个陷阱（如加限制域、改单位、增无关数据），练审题。
   - 例：原「求正整数解」，变「求负整数解」；原无单位，变「结果以厘米为单位」。
3. **逆向提问** — 把已知与未知对调（已知结果求其中一个条件），练概念迁移。
   - 例：原「已知速度求时间」，变「已知时间和路程，求速度」；原「求面积」，变「已知面积和一边长，求另一边长」。
