# 错题讲解模板

复制本文件填充。诊断必须引用学生作答的具体步骤；变式题答案需先自验再填。

```
## 正确答案
[题号] [正确答案，附简要求解过程]

## 错因诊断
- 类型：[六类之一，可组合，主次分明]
- 依据：学生第 [X] 步「[原话 / 原算式]」→ 这里 [具体错在哪]
- 说明：[一句话点清为什么错]

## 第 1 级提示（默认给出）
[点方向不点破的一句话]

> 学生需要时再依次给：
> 第 2 级提示：[给关键一步]
> 第 3 级提示：[完整思路，仍不直接给最终答案]

## 变式题（3 道，答案折叠）
1. [同结构换数字] 题目：[...]
   答案与解析：[自验后的答案 + 要点]
2. [换干扰条件] 题目：[...]
   答案与解析：[自验后的答案 + 要点]
3. [逆向提问] 题目：[...]
   答案与解析：[自验后的答案 + 要点]

## 复测判定
- 学生作答：[粘贴]
- 判定：[已掌握 / 未掌握 → 回到错因诊断换讲解路径]
```

## 填写约束

1. 错因诊断必须带「依据：学生第 X 步……」的引用，不得只贴类型名
2. 默认只输出第 1 级提示；第 2、3 级标注「学生需要时再给」
3. 3 道变式题必须覆盖三种类型，且答案先自验再填
4. 变式题难度不得超出用户所给学段
5. 复测判定留空，等学生作答后回填
